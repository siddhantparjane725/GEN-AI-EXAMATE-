# MatdarMitra – 10 Real User Questions

These questions represent realistic situations that citizens may ask while seeking voter registration assistance.

## Original Project Card Questions

**Q1.** What documents are needed with Form 6?

**Q2.** Which form should I fill to correct my name spelling on voter ID?

**Q3.** Who can object to someone's name in the voter list?

**Q4.** I was born on 14 March 2008 and shifted from Shrirampur to Kopargaon, which form and from which date can I vote here?

**Q5.** My grandfather died last year, how do we remove his name and also correct my mother's age in one visit?

**Q6.** Who is the BLO for ward 5 in Kopargaon?

> **Important:** The current MatdarMitra dataset cannot answer Q6 because it does not contain verified ward-wise BLO contact information. The system should explain this limitation and direct the user to official ECI channels instead of inventing a name or phone number.

## Additional User Questions

**Q7.** I am an Indian citizen living abroad. How can I register as an overseas voter?

**Q8.** Is providing an Aadhaar number compulsory for voter registration?

**Q9.** I have shifted to a new address. Which form should I submit to update my voter registration?

**Q10.** Can I apply for voter registration online, or do I need to submit a physical signed form?

## Purpose of These Questions

These questions will help test whether MatdarMitra can:

- Identify the appropriate ECI form.
- Retrieve required document information.
- Understand voter eligibility-related questions.
- Handle correction, deletion and shifting requests.
- Recognize questions that cannot be answered using the current dataset.
- Avoid generating unsupported official contact information.
